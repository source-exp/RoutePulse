# Project context

- This repository contains the TypeScript kit and dispatch starter for Spread.
- Give your agent this link: https://spread.bahnexpress.com/llms.txt
- Set `SPREAD_URL=https://spread.bahnexpress.com` and `SPREAD_KEY` to the team key in the process environment before running Spread commands.
- Never save `SPREAD_KEY` in this repository, source files, logs, or committed configuration. Use a local, untracked environment file or export it in your shell.

## Run results

- Always save the complete console output from every practice, ranking, or final run under `results/`.
- Use a descriptive filename with the run date and purpose (for example, `results/2026-11-13-level-8-practice.log`).
- Keep generated run data and summaries in `results/`; do not overwrite prior runs.
